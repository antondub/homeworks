# Узлы

Описание, без прошивки. База ESP32 и до 4 модулей по SPI. Дома тот же узел на штатном ESPHome. В комплексе база на CAN с промышленным компьютером RK3566.

Схемы: [модули](modules.md), [шина](bus.md), [4PWM](4pwm.md).

## Устройство

База — мастер-модуль: ESP32, CAN-трансивер и шина на 4 модуля расширения. Модуль расширения на CAN не выходит.

Тип канала: `DI`, `DQ`, `AI`, `AQ`.

В ряд ставится модуль одного типа каналов: `8DI`, `8DQ`, `4AI`, `2AQ`, `4PWM`. Полевые цепи на модуле. Пустое место — вставка со сдвигом CS.

Пример стойки на 12 аналоговых входов и выходы: три `4AI` и один `8DQ`.

```yaml
node:
  name: station
  board: esp32

rack:
  - 4AI
  - 4AI
  - 4AI
  - 8DQ

channel:
  - ch: 1
    type: AI
    id: ai
    can: 0x201
    every: 10ms
    calibrate:
      zero: 0
      mul: 1000
      div: 1
  - ch: 1
    type: DQ
    id: out
    can: 0x281
```

Каналы 2–12 `AI` и остальные `DQ` — такие же записи, у каждого `AI` своя калибровка. `can` — ID кадра, смысл данных, не адрес платы.

## Дома

Домашняя поделка — штатный ESPHome, исходники ESPHome не меняются. `8DQ` — платформа `sn74hc595`. `4PWM` — внешний компонент: база пишет по SPI длительность импульса, ШИМ считает модуль.

## Комплекс

Мастер — одноплатник RK3566, сенсорная TFT 7–10 дюймов (HDMI и USB-тач мастера), веб-интерфейс. USB только у мастера. Своего CAN у RK3566 нет: адаптер SocketCAN, USB-CAN или SPI на 40-pin.

Остальные устройства комплекса — базы ESP32 на CAN. Кадр никому не адресован. База вещает `DI` и `AI`, компьютер слушает и по логике вещает `DQ` и `AQ`. База фильтром берёт ID своих выходов и выставляет их на SPI-модуль.

`DI` и `AI` идут циклически, для быстрых каналов 2–10 мс. За этот срок база успевает опросить свои 4 модуля по SPI и положить новые значения на CAN. `DI` дополнительно сразу при изменении. Нет кадров ID дольше его периода — данных нет. Меньший ID проходит раньше, если два узла передают одновременно.

При старте база обходит ряд и сверяет дочерние платы с местами в своей конфигурации. Ряд сошёлся — база каждые 100–500 мс шлёт статус, что она исправна. Нет платы на месте или другой тип — в статусе нет «ок».

У компьютера свой YAML: экраны, формулы и логика. Калибровка `AI` лежит в записи канала.

```yaml
hmi:
  name: example

screen:
  - name: work
    widget:
      - type: number
        source: value
        ch: 1-12
      - type: switch
        node: station
        channel: DQ
        target: out
  - name: channel
    node: station
    ch: 1-12
    edit: calibrate

formula:
  - id: value
    expr: (raw - calibrate.zero) * calibrate.mul / calibrate.div

logic:
  - id: act
    from: AI
    use: value
    when: value > target
    do:
      - can: out
        ch: same
        value: 1
```

Набор экранов как у средней панели: переход, лампа, кнопка и переключатель, число и шкала, ввод уставки, аварии и квитирование, тренд, оператор и наладчик.

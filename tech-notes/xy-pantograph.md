# 🦾 Горизонтальный Х-манипулятор на базе 4-рычажного ременного пантографа

Инженерное описание и кинематическая схема жесткого горизонтального манипулятора, закрепленного на подвижной каретке декартовой системы (оси YZ) и осуществляющего перемещение рабочего узла (головы) строго вдоль оси X с вылетом до 80–100 см.

## 📌 Краткие технические характеристики

*   **Рабочий ход по оси X:** 80–90 см (вылет до 1 метра).
*   **Максимальный вес головы (инструмента):** до 2 кг.
*   **Тип механики:** 4-рычажный зеркальный пантограф.
*   **Материал каретки:** Стальная плита (раскрой на плазморезе).
*   **Материал плеч:** Пространственная объемная ферма из стального уголка 25х25 мм.
*   **Тип привода:** Один шаговый двигатель (NEMA 23) с ременной редукцией 3:1 и функцией выворотной петли.
*   **Основные валы:** Сталь Ст45, диаметр 20–25 мм.

---

## 📐 Кинематические схемы

### 1. Вид сверху (Ременная синхронизация и редукция 3:1)

Один замкнутый широкий ремень решает одновременно две задачи: обеспечивает понижение передачи от мотора 3:1 и задает жесткое зеркальное вращение Вала А и Вала Б в противоположные стороны. Это полностью исключает люфты, свойственные шестеренчатым передачам.

```text
                   [ Направляющая оси Y портала ]
=================================||=================================
                                 ||
                           [ Каретка Y ]
            ┌─────────────────────────────────────────────┐
            │                                             │
       ( Вал А - Ведущий )                           ( Вал Б - Ведомый )
         [ ШКИВ А 60Т ]                                [ ШКИВ Б 60Т ]
            │      ▲                                      ▲      │
            │      │    ┌────────────────────────────┐    │      │
            │      │    │                            │    │      │
            │      └────┼───────► [ Ролик 1 ] ◄──────┼────┘      │
            │           │          (Гладкий)         │           │
            │           ▼                            ▼           │
            │       [ Ролик 2 ]                  [ Натяжитель ]  │
            │        (Гладкий)                     (Ролик)       │
            │           ▲                                        │
            │           │                                        │
            └───────────┼───────► [ Шкив Мотора ] ◄──────────────┘
                                      ( 20 Тек )
```

### 2. Вид сбоку в разрезе (Двухопорная жесткая структура фермы)

Плечи разделены на «верхний» и «нижний» этажи, образуя пространственную коробчатую ферму. Это полностью ликвидирует скручивание, люфт по оси Z и провисание инструмента под собственным весом на максимальном вылете.

```text
   [ Плечо 1 Верхнее ]                       [ Плечо 2 Верхнее ]
         │                                         │
   ┌─────┴─────────────────────────────────────────┴─────┐ ◄ Верхняя пластина каретки
   │ [Подшипник 1]                           [Подшипник 3] │
   │                                                       │
   │  [Один ремень петлей HTD5M 15мм] ◄═════════► [Мотор]  │ ◄── Зона привода и синхронизации
   │                                                       │
   │ [Подшипник 2]                           [Подшипник 4] │
   └─────┬─────────────────────────────────────────┬─────┘ ◄ Нижняя пластина каретки
         │                                         │
   [ Плечо 1 Нижнее ]                        [ Плечо 2 Нижнее ]
         │                                         │
         ▼ (Длина 50 см)                           ▼ (Длина 50 см)
   (Блок шарниров «Локоть»)                  (Блок шарниров «Локоть»)
         │                                         │
   [ Плечо 3 (Верх + Ниж) ]                  [ Плечо 4 (Верх + Ниж) ]
         │                                         │
         ▼                                         ▼
   ┌─────────────────────────────────────────────────────┐
   │          Конечная площадка (Голова робота, 2 кг)    │
   └─────────────────────────────────────────────────────┘
```

## 🛠️ Особенности конструкции и узлы

### 1. Пространственная ферма из уголка 25х25 мм
Чтобы избежать закручивания и провисания одиночного уголка, верхняя и нижняя половинки плеч собираются в ажурную строительную ферму. Полки уголков ориентируются наружу, а во внутреннее пространство ввариваются наклонные перемычки (раскосы) из стальной полосы толщиной 3-4 мм. Сварка выполняется строго на жестком стапеле короткими прихватками в шахматном порядке для предотвращения поводок металла.

### 2. Узел фиксации «Вал – Уголок» через пропилы
Для надежной передачи крутящего момента на концах валов 20-25 мм (Сталь Ст45) болгаркой или фрезой делаются параллельные пропилы с двух сторон, формируя плоский прямоугольный шип толщиной 8–10 мм с плавным радиусным переходом к круглому телу вала (для исключения концентраторов напряжения). В полку уголка вваривается усиливающая пластина-накладка, после чего узел садится внатяг на шип вала и намертво стягивается сквозным высокопрочным болтом класса 8.8 / 10.9, работающим на чистый срез.

### 3. Распределение динамических нагрузок
При вылете стрелы на 1 метр статический изгибающий момент от веса головы составляет ~20 Н·м. В моменты резких стартов и остановок (реверсов) инерционные силы кратковременно увеличивают момент в этой точке до **60–80 Н·м**. Нагрузка на разрыв плеча синхронизирующего ремня при этом может достигать эквивалента **130 кг**. 

Для компенсации этих сил в конструкции применены:
*   Фланцевые подшипниковые узлы серии **UCFL / UCF** (например, UCF204 или UCF205), закрепленные болтами на овальные пазы в стальной каретке для точной регулировки зазора.
*   Широкий силовой ремень профиля **HTD5M (ширина 15 мм)** со стекловолоконным или металлическим кордом.

## 💻 Программное управление
В связи с тем, что эластичность ремня на максимальном рычаге является основным гибким элементом системы, для предотвращения остаточных вибраций головы («тряски как желе») в прошивке контроллера (GRBL, LinuxCNC или кастомный ПЛК) для оси X должны быть настроены **плавные S-образные графики ускорения (S-curve acceleration)** вместо линейных трапецеидальных.

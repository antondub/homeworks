# HomeESP

Прошивки ESPHome для Home Assistant. Секреты Wi‑Fi — `secrets.yaml`, в репозиторий не входят. Часовой пояс устройств — Europe/Moscow.

## heatingOld

Котловой контур. Плата ESP8266, NodeMCU v2. Файл: [heater_esp32.yaml](heater_esp32.yaml). Имя в HA: `heatingOld`.

1-Wire на GPIO5, Dallas, разрешение 12 бит.

| Датчик | Имя | Период |
| --- | --- | --- |
| верх контура | TempHeaterTop | 30 с |
| низ контура | TempHeaterDown | 30 с |
| улица | TempOut | 120 с |
| помещение | TempIn | 60 с |

ТЭНы, slow PWM 30 с:

| Выход | Пин | Мощность |
| --- | --- | --- |
| heater1 | GPIO15 | 2 кВт |
| heater2 | GPIO12 | 4 кВт |

GPIO14 и GPIO13 в конфиге есть, к ТЭНам не подключены.

Считается каждые 30 с по приходу `TempHeaterTop`. Ручной режим: уставка перепада 0.

Уставка комнаты `targ` — дневная, а при включённом день/ночь и часе &lt; 7 или &gt; 21 — ночная.

```
Q_loss = V · k · (targ − TempOut)
Q_in   = (V · k + trim) · (targ − TempIn)   # 0, если TempIn нет
Q_need = max(Q_loss + Q_in, 0)      # Вт
Q_now  = 1.163 · G · (верх − низ)   # Вт; G — расход воды, л/ч
Δ      = Q_need / (1.163 · G)       # °C, только при G > 1 л/ч
```

`Δ` — нужный перепад верх−низ, 0…40 °C. Цель PID — температура верха: `низ + Δ`, не выше 55 °C. Датчик PID — `TempHeaterTop`. Коэффициенты: kp 0.21236, ki 0.00177, kd 6.37080. Мёртвая зона ошибки: −0.1…+0.5 °C. Выход PID `s` — 0…0.85, период slow PWM 30 с.

Скважности ТЭНов от `s`:

```
s = 0        → оба 0
s < 0.275    → ТЭН1 = 3s + 0.033, ТЭН2 = 0
s < 0.55     → ТЭН1 = 0,          ТЭН2 = 1.5s + 0.033
иначе        → оба = s + 0.033
P = l1·2 кВт + l2·4 кВт
```

`Heat Power` — среднее `P` за 10 отсчётов. Верх выше 65 °C — оба ТЭНа выключаются.

Константы в HA: `V` — объём, м³; `k` — удельные потери, Вт/м³·К; `G` — расход воды, л/ч; `trim` — добавка по TempIn, Вт/К; мощность каждого ТЭНа. Пока `V`, `k` или `G` равны 0, `Q_need` не задаёт нагрев.

Рабочие значения: `V = 125`, `k = 0.95`, `G = 170`. Ночь 22.10, улица 12 °C, кухня 20.3 °C: при `k = 0.7` выходило ~800 Вт и дом остывал. На эту точку нужно 1000–1200 Вт. `k = 0.95` даёт ~1150 Вт, пока кухня 20.3 °C, и ~1070 Вт, когда она уже на уставке 21. При −10 °C и комнате на уставке ~3.7 кВт, при −20 °C ~4.9 кВт.

Если на ровном режиме `Heat Power` и перепад не сходятся: `G = Heat Power · 1000 / (1.163 · (верх − низ))`, затем `k` умножить на `170 / G`.

## oilburner

Горелка на отработке. Плата ESP32. Файл: [oil-burner_esp32.yaml](oil-burner_esp32.yaml). Имя в HA: `OilBurner`. Железо: [горелка и котёл](../blueprints/burner/README.md).

| Сигнал | Пин |
| --- | --- |
| пламя, MAX6675 CS | GPIO27, SPI GPIO12/13/14, 1 с |
| вода, Dallas | GPIO32, 10 с |
| импульсы насоса | GPIO4, LEDC |
| разрешение насоса | GPIO5, инверсия |
| вентилятор | GPIO22, LEDC 25 кГц |

Подача — шаговый насос, порция раз в `period` = 4 с. `MlMin` в мл/мин. На оборот 5 мл и 20000 импульсов, разгон с 2000 Гц шагом 1200 Гц до 20000 Гц.

```
pulses = (MlMin / 60 · period) / 5 · 20000
```

`MlMin = 0` останавливает насос.

Вентилятор после пуска не останавливают на короткое время. `Start`, `Stop/Auto`, `Fan` и цикл 10 с заново делают `turn_on` и сдвигают таймер выключения на 200 с. Снятие `fanOn` и пауза 600 с — только если пламя ниже 200 °C; сам `turn_off` ещё через этот таймер. Ниже 12.5 % скорость не ставят.

Кнопки:

- `Start` — подача 10 мл/мин, вентилятор, счётчик погасания −5
- `Stop/Auto` вкл — авто, стадия 1, вентилятор, счётчик −5
- `Stop/Auto` выкл — подача 0, стадия 2
- `Fan` — только включить, если ещё выключен

Каждые 10 с по пламени `bT` и воде `tT`, уставка воды `aT`, заданный расход `F`:

```
bT < 200, стадия 2, счётчик > 2     → авто выкл, подача 0
bT < 50,  стадия 1, счётчик > 10    → то же
bT > 200                            → стадия 2, счётчик 0
tT ≥ aT                             → подача 10; Heating Once — подача 0 и авто выкл
tT ≤ aT − 0.5, bT < 100             → подача не выше 10
tT ≤ aT − 0.5, bT < 250             → подача не выше 15
текущая подача < цели − 5           → цель · 1.1
```

Скорость вентилятора от числа `Fan Speed` в авто: `bT < 100` и стадия ещё не 2 — ×0.45, `bT > 250` — ×1.45, иначе ×0.9. Без авто: `bT < 100` — ×0.45, иначе ×1.

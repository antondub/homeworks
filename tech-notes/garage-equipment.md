# 🛠 Инженерная мастерская: Оборудование и станкостроение

Документация по модернизации существующего станочного парка и проектированию нового оборудования для гаража.

---

## 🔥 Существующий арсенал (Техническая база)

Для проведения всех работ по дому и станкостроению задействуется следующий сварочно-заготовительный комплекс:
*   **Сварка и резка:** MMA (штучный электрод), MIG/MAG (полуавтомат для быстрой сборки конструкций), TIG AC/DC (аргонодуговая сварка для точных швов, нержавейки и алюминия), Плазморез (быстрый раскрой листового металла).
*   **3D-печать:** Одноэкструдерный принтер на MKS DLC32, прошивка Marlin 2.1. Подробности: [mks-dlc32-printer.md](./mks-dlc32-printer.md).

## 🔧 Программа модернизации оборудования (TODO & Тюнинг)

### 1. Токарный станок (Малый, макс. Ø 180 мм)
*   **Проблема:** Недостаточная жесткость легкой станины, ограничения по диаметру обработки, слабый привод.
*   **Задачи по апгрейду:**
    - [ ] **Усиление жесткости:** Заливка/заполнение полостей станины полимербетоном для гашения вибраций.
    - [ ] **Повышение точности:** Шабрение направляющих, регулировка/замена подшипников шпинделя.
    - [ ] **Увеличение мощности:** Установка более мощного электродвигателя (возможно, с частотным преобразователем).
    - [ ] **Расширение возможностей:** Изготовление проставок под переднюю и заднюю бабку (подъем патрона) для увеличения максимального диаметра обрабатываемой детали.

### 2. Сверлильный станок
*   **Проблема:** Общий износ («потрепанное» состояние), люфты, проблемы с механикой.
*   **Задачи по апгрейду:**
    - [ ] Перебрать и дефектовать шпиндельный узел, разобраться с биением патрона.
    - [ ] Модернизировать приводной механизм (шкивы, ремни).
    - [ ] Рассмотреть замену двигателя на более мощный и выносливый.

### 3. Вальцы листовые (Рабочая зона ~300 мм)
*   **Текущий статус:** Собраны, катают лист в трубу (необходимо для изготовления элементов котла и дымоходов). Требуют финишной доработки.
*   **Задачи по апгрейду:**
    - [ ] Изготовить упорные пятки/подпятники для прижимных винтов, чтобы винты не сжирали металл ползунов при регулировке зазора.

### 4. Принтер на MKS DLC32
*   **Текущий статус:** Плата V2.1/V2.2, Marlin `bugfix-2.1.x`, среда `mks_dlc32_v2_1`. X/Y/Z — TB6600, экструдер в сокете Z. Хотэнд — MAX6675, стол — NTC и реле. Прошивка стартует, хост — USB 250000 и веб `http://marlinesp.local`.
*   **Документация:** [Разводка, пины и первый пуск](./mks-dlc32-printer.md), схема [mks-dlc32/wiring.svg](./mks-dlc32/wiring.svg).
*   **Дальше на столе:** калибровка `steps/mm` и направлений, `M119`, ПИД хотэнда, хоуминг.

*   **Конструкция:** Проектирование жесткой прижимной и поворотной балки из швеллеров/двутавров с использованием мощных петель.

### 2. Большой гранульный 3D-принтер (Pellet Extruder)
*   **Концепция:** Крупноформатный принтер для дешевой и быстрой печати массивных деталей вторичным пластиком (дробилкой, гранулами ПЭТ/ПНД).
*   **Технические параметры:**
    - Шнековый экструдер (подача гранул с помощью сверла по дереву или кастомного шнека в зоне нагрева).
    - Сопло увеличенного диаметра: **1.0 – 2.0 мм** для высокой скорости возведения стенок.
    - Мощная кинематика (профильные направляющие, рама из станочного алюминиевого профиля или сварная стальная).

## 🛠 Краткое описание узлов

### 1. Отопление (Жидкотопливная горелка + котел из бочки 30л)
*   **Концепция:** Уличный котельный модуль на отработанном масле в защитном ящике.
*   **Текущий статус:** Изготовление горелки (вырезаны 2 сложные пластины из 6).
*   **Документация:** [Инструкция и логика работы горелки](./blueprints/burner/README.md).

### 2. Пол 2-го этажа (Микроцемент SlimBeton)
*   **Технология:** 
    1. База: плиточный клей ТиМ Гранит №36 (C2TS1) + акриловая грунтовка-концентрат + зеленый пигмент + сетка.
    2. Финиш: микроцемент SlimBeton светлых оттенков «на сдир» для контраста.
    3. Защита: однокомпонентный полиуретановый лак Antega Lux в 2 слоя.
*   **Документация:** [Технологическая карта и ссылки на закупку](./tech-notes/microcement.md).

### 3. Оборудование для гаража
*   **В планах:** Листогибочный станок, большой шнековый 3D-принтер под гранулы (сопло 1–2 мм).
*   **Что есть:** Сварочный пост (MMA/MIG/TIG/плазма), малый токарный (до Ø180 мм), сверлильный, вальцы (~300 мм), принтер Anet A8.
*   **Документация:** [План модернизации станков и проекты самоделок](./tech-notes/garage-equipment.md).

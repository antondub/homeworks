## 🛠 Краткое описание узлов

### 1. Отопление (Жидкотопливная горелка + котел из бочки 30л)
*   **Концепция:** Уличный котельный модуль на отработанном масле в защитном ящике.
*   **Текущий статус:** Изготовление горелки (вырезаны 2 сложные пластины из 6).
*   **Документация:** [Инструкция и логика работы горелки](./blueprints/burner/README.md).

### 2. Пол 2-го этажа (Микроцемент SlimBeton)
*   **Технология:** 
    1. База: плиточный клей ТиМ Гранит №36 (C2TS1) + акриловая грунтовка-концентрат + зеленый пигмент + сетка.
    2. Финиш: микроцемент SlimBeton светлых оттенков «на сдир» для контраста.
    3. Защита: однокомпонентный полиуретановый лак Antega Lux в 2 слоя.
*   **Документация:** [Технологическая карта и ссылки на закупку](./tech-notes/microcement.md).

### 3. Оборудование для гаража
*   **В планах:**
    *   **Листогибочный станок:** для гибки жести под парапеты крыши на месте.
    *   **Большой 3D-принтер:** шнековый экструдер, печать гранулами и крошкой пластика через сопло 1–2 мм.
*   **Что уже есть и требует доработки:**
    *   **Сварочный пост:** MMA, MIG/MAG, TIG (AC/DC), плазморез.
    *   **Токарный станок:** малый (до Ø180 мм). План: залить станину бетоном, поднять бабки для увеличения диаметра обработки, заменить мотор.
    *   **Сверлильный станок:** потрепанный. План: убрать люфт патрона, перебрать привод, поставить мощный двигатель.
    *   **3D-принтер Anet A8:** экструдер переделан (Direct). План: заменить плату управления, поставить промышленные драйверы и датчик автоуровня.
    *   **Вальцы (~300 мм):** готовы. План: сделать опорные пятаки для прижимных винтов.

## 🚀 Как работать с репозиторием

1.  **Сделал шаг в задаче?** Открой `todo.md`, поставь `[x]` напротив пункта, сделай коммит:
    ```bash
    git commit -am "fix(todo): отметил готовую базу пола в спальне"
    ```
2.  **Изменил чертеж?** Замени файл в папке `blueprints/` новым экспортом, чтобы под рукой всегда была актуальная схема.
3.  **Подобрал удачный колер?** Запиши пропорции в `tech-notes/microcement.md`, чтобы холл и детская не отличались по оттенку от спальни.

## 🧠 Инженерные размышления (В очереди на проработку)

### 🚰 Схемы коммуникаций (Водопровод и слив)
Перед тем как закупать трубы и фитинги для восстановления (п. 3 в TODO), необходимо решить несколько организационных и технических вопросов:
*   **Где разместить?** Определить оптимальные точки прохода труб сквозь перекрытия и стены, чтобы минимизировать штробление и не ослабить несущие конструкции.
*   **В каком формате делать схему?** 
    *   *Вариант А:* Начертить 2D-схему (аксонометрию) в CAD-программе и выгрузить в PDF/PNG в папку `blueprints/`.
    *   *Вариант Б:* Нарисовать от руки на миллиметровке, отсканировать/сфотографировать и прикрепить сюда.
    *   *Вариант В:* Сделать схему прямо в Markdown с помощью текстовых диаграмм Mermaid (код, который GitHub автоматически превращает в блок-схемы).
*   **Трассировка:** Подумать, как пустить фановую трубу и трубы ХВС/ГВС, чтобы к ним оставался ревизионный доступ, но при этом они не портили внешний вид комнат.

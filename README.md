## 🛠 Краткое описание узлов

### 1. Отопление (горелка на отработке + котёл из кеги 30 л)
*   **Концепция:** Уличный модуль в ящике. Горелка с испарительной чашей и циклоном; теплообменник — горизонтальная нержавеющая кега, внутри жаровой стакан Ø200. Ориентир съёма с одной кеги — порядка 10 кВт. Вторая кега на выхлопе — позже.
*   **Текущий статус:** Пластины вставки горелки готовы, сборка и циклон ещё нет. Котёл на бумаге.
*   **Документация:** [Горелка и котёл](./blueprints/burner/README.md).

![Разрез котла](./blueprints/burner/котел-кега-30л.svg)

### 2. Пол 2-го этажа (Микроцемент SlimBeton)
*   **Технология:** 
    1. База: плиточный клей ТиМ Гранит №36 (C2TS1) + акриловая грунтовка-концентрат + зеленый пигмент + сетка.
    2. Финиш: микроцемент SlimBeton светлых оттенков «на сдир» для контраста.
    3. Защита: однокомпонентный полиуретановый лак Antega Lux в 2 слоя.
*   **Документация:** [Технологическая карта и ссылки на закупку](./tech-notes/microcement.md).

### 3. Оборудование для гаража
*   **В планах:** Листогибочный станок, большой шнековый 3D-принтер под гранулы (сопло 1–2 мм).
*   **Что есть:** Сварочный пост (MMA/MIG/TIG/плазма), малый токарный (до Ø180 мм), сверлильный, вальцы (~300 мм), принтер на **MKS DLC32** (Marlin 2.1).
*   **Документация:** [План модернизации станков](./tech-notes/garage-equipment.md), [принтер на DLC32](./tech-notes/mks-dlc32-printer.md).
